# Base de connaissances

Ce dossier est destiné à accueillir des études et références (neurosciences, linguistique, etc.)
qui alimenteront les règles d'analyse.

Exemples de sujets à intégrer :
- Études sur la longueur optimale des phrases pour la compréhension orale
- Limites cognitives sur le traitement des chiffres à l'oreille
- Impact des exemples concrets vs. données abstraites sur la mémorisation
- Rythme et souffle : durée optimale d'une unité de sens parlée
